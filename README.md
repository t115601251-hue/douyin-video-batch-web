# 抖音视频批量提取器（网页端）

本地网页应用：粘贴抖音视频链接、核对作品、选择可用分辨率，然后批量保存为 MP4。

## 使用

1. 双击 `双击启动.bat`，浏览器会打开本机网页；关闭启动窗口会停止服务。
2. 在输入框粘贴链接或分享文案。链接可分行，也可以连续粘贴，例如 `链接1https://链接2`；程序会自动分开识别。支持 `/video/作品ID`、`jingxuan?modal_id=作品ID` 和抖音短链接。
3. 点击“解析并核对链接”，确认标题、作者和作品 ID。
4. 填写本机保存路径并点击“确认目录”。路径不存在时会创建；没有权限时会明确提示。
5. 选择分辨率后批量下载。每个作品只保存一个 MP4 文件。

默认保存目录是程序旁的 `downloads`。程序只监听 `127.0.0.1`，只能在本机访问。

## GitHub

提交源码时不需要上传 `python_env`、`downloads`、`settings.json` 和日志文件，仓库中的 `.gitignore` 已排除这些本地运行内容。

使用系统 Python 时先安装依赖：

```powershell
pip install -r requirements.txt
python web_server.py
```

程序只处理公开可访问的视频链接；私密、失效或需要登录/验证的内容可能无法解析。
